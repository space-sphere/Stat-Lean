    Product-likelihood comparisons #

    These adapters transfer exact product maximization to empirical log-likelihood comparisons without assuming positivity. The only failure event is that the fixed comparator density vanishes at some sampled coordinate.

    source
    theorem AsymptoticStatistics.MaximumLikelihood.sampleLikelihood_zero_probability_le {X : Type u_1} {Θ : Type u_2} [MeasurableSpace X] (M : ParametricFamily X Θ) (P₀ : MeasureTheory.Measure X) (θ : Θ) (n : ℕ) {Ω : Type u_3} [MeasurableSpace Ω] (P : MeasureTheory.Measure Ω) (Xs : ℕ → Ω → X) (hXs_meas : ∀ (i : ℕ), Measurable (Xs i)) (hXs_id : ∀ (i : ℕ), ProbabilityTheory.IdentDistrib (Xs i) (Xs 0) P P) (hXs_law : MeasureTheory.Measure.map (Xs 0) P = P₀) :
    P.real {ω : Ω | (sampleLikelihood M θ n fun (i : Fin n) => Xs (↑i) ω) = 0} ≤ ↑n * P₀.real {x : X | M.density θ x = 0}

    The probability that a fixed comparator has zero product likelihood is at most n times its one-observation zero-density probability.

    At every fixed local direction, an exact product MLE is an empirical log-likelihood near-maximizer in probability. DQM makes the probability of a zero comparator product vanish at the required n⁻¹ scale.
