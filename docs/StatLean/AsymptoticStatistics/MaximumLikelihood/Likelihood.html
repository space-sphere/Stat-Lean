    Likelihood of a finite sample #

    This file records the product likelihood used by maximum-likelihood estimators. The definition is valid at n = 0, where the empty product is 1.

    source
    noncomputable def AsymptoticStatistics.MaximumLikelihood.sampleLikelihood {X : Type u_1} {Θ : Type u_2} [MeasurableSpace X] (M : ParametricFamily X Θ) (θ : Θ) (n : ℕ) (x : Fin n → X) :
    ℝ

    The likelihood of a parameter at a finite sample is the product of its density values. At the empty sample this is the empty product 1.

    • AsymptoticStatistics.MaximumLikelihood.sampleLikelihood M θ n x = ∏ i : Fin n, M.density θ (x i)
