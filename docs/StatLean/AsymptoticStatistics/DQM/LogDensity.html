    DQM and differentiability in probability of the log density #

    This file records the probability-level bridge used in van der Vaart, Asymptotic Statistics, Theorem 5.39: differentiability in quadratic mean implies differentiability in probability of the log-density criterion, with derivative given by the score.

    The bridge does not assume strict positivity of nearby densities. The proof must isolate the zero-density exceptional sets and use DQM to show that they vanish in probability under the true distribution.

    The real log density log p_theta(x) used as the MLE criterion in vdV Theorem 5.39.

    Edge behavior: Mathlib defines Real.log 0 = 0. At the true parameter this convention changes the function only where p_theta0 = 0, a null set under the true density. For nearby parameters the DQM-to-probability bridge below handles their zero sets as exceptional events; it does not assume strict positivity.
