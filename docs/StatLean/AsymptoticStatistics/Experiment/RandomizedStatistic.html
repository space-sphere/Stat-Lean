    Randomized statistics as Markov kernels #

    A randomized statistic in an experiment indexed by h ∈ Θ is, in van der Vaart's original presentation, a measurable function T(X, U) with auxiliary uniform U. The kernel-theoretic equivalent (taken here as primary) is a Markov kernel κ : Kernel Θ 𝓨. Given a law-of-observation map ν : Θ → Measure Θ (e.g. the Gaussian shift family), the induced law of the randomized statistic at parameter h is (ν h).bind κ : Measure 𝓨.
