    Diagonal-attaining sub-sequence on a monotone finite-index chain #

    This file provides the diagonal-attaining Tendsto form of the Cantor-diagonal sub-sequence extraction on a monotone finite-index chain: given a monotone chain of finsets I k and a doubly-indexed family a n h, one can extract a diagonal sub-sequence φ along which ⨆ h ∈ I k, a (φ k) h converges to ⨆ k, liminf_n ⨆ h ∈ I k, a n h.

    The headline declaration is diagonal_subseq_attaining_lim_sup_finset. It pairs naturally with exists_strictMono_tendsto_liminf_ennreal for extracting a diagonal sub-sequence attaining the ⨆_k liminf_n of a per-finset-sup quantity.

    Helpers: ENNReal cluster-point liminf-attainer #

    Two lemmas about ENNReal-valued sequences, used to build diagonal_subseq_attaining_lim_sup_finset and reusable on their own.

    source
    theorem AsymptoticStatistics.Prohorov.frequently_mem_nhds_liminf_ennreal (u : ℕ → ENNReal) {s : Set ENNReal} (hs : s ∈ nhds (Filter.liminf u Filter.atTop)) :
    ∃ᶠ (n : ℕ) in Filter.atTop, u n ∈ s

    In ℝ≥0∞, every open neighbourhood of Filter.liminf u atTop is frequently hit by u. This is the cluster-point property of liminf, specialised to ENNReal (where IsBounded side-conditions are automatic).

    Paired with exists_strictMono_tendsto_liminf_ennreal, which packages this fact into the diagonal-extraction form ∃ ψ, u ∘ ψ ⟶ liminf u.

    source
    theorem AsymptoticStatistics.Prohorov.exists_strictMono_tendsto_liminf_ennreal (u : ℕ → ENNReal) :
    ∃ (ψ : ℕ → ℕ), StrictMono ψ ∧ Filter.Tendsto (u ∘ ψ) Filter.atTop (nhds (Filter.liminf u Filter.atTop))

    For each sequence u : ℕ → ℝ≥0∞, there exists a strictly monotone extraction ψ : ℕ → ℕ along which u ∘ ψ converges to Filter.liminf u atTop.

    Combines frequently_mem_nhds_liminf_ennreal (cluster-point property) with TopologicalSpace.FirstCountableTopology.tendsto_subseq.

    Main theorem: diagonal Cantor extraction on a monotone finset chain #

    source
    theorem AsymptoticStatistics.Prohorov.diagonal_subseq_attaining_lim_sup_finset {α : Type u_1} (I : ℕ → Finset α) (h_mono : ∀ (k : ℕ), I k ⊆ I (k + 1)) (a : ℕ → α → ENNReal) :
    ∃ (φ : ℕ → ℕ), StrictMono φ ∧ Filter.Tendsto (fun (k : ℕ) => ⨆ h ∈ I k, a (φ k) h) Filter.atTop (nhds (⨆ (k : ℕ), Filter.liminf (fun (n : ℕ) => ⨆ h ∈ I k, a n h) Filter.atTop))
