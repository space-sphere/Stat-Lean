    Algebraic operations preserving TendstoInMeasure ... 0 #

    Mathlib's TendstoInMeasure API (Mathlib.MeasureTheory.Function.ConvergenceInMeasure) provides congr_left, congr_right, mono, comp, but no direct algebraic operations (add, neg, sub, const_mul) for the case where the limit is the zero function. We package those here for real-valued sequences.

    Headline declarations: TendstoInMeasure.neg_zero, TendstoInMeasure.const_mul_zero, TendstoInMeasure.add_zero, TendstoInMeasure.sub_zero.

    The declarations below provide this zero-limit algebra for real-valued sequences.

    theorem MeasureTheory.TendstoInMeasure.neg_zero {α : Type u_1} {ι : Type u_2} {m : MeasurableSpace α} {μ : Measure α} {l : Filter ι} {f : ι → α → ℝ} (hf : TendstoInMeasure μ f l fun (x : α) => 0) :
    TendstoInMeasure μ (fun (n : ι) => -f n) l fun (x : α) => 0

    -f →_P 0 from f →_P 0. Proof: convert on edist (-f n ω) 0 = edist (f n ω) 0 via enorm_neg.

    theorem MeasureTheory.TendstoInMeasure.const_mul_zero {α : Type u_1} {ι : Type u_2} {m : MeasurableSpace α} {μ : Measure α} {l : Filter ι} (c : ℝ) {f : ι → α → ℝ} (hf : TendstoInMeasure μ f l fun (x : α) => 0) :
    TendstoInMeasure μ (fun (n : ι) (ω : α) => c * f n ω) l fun (x : α) => 0

    c · f →_P 0 from f →_P 0. Proof: case-split c=0 (trivial: set is empty), c≠0 (scale ε by 1/‖c‖ₑ via enorm_mul for ℝ + ENNReal.le_div_iff_mul_le).

    theorem MeasureTheory.TendstoInMeasure.add_zero {α : Type u_1} {ι : Type u_2} {m : MeasurableSpace α} {μ : Measure α} {l : Filter ι} {f g : ι → α → ℝ} (hf : TendstoInMeasure μ f l fun (x : α) => 0) (hg : TendstoInMeasure μ g l fun (x : α) => 0) :
    TendstoInMeasure μ (fun (n : ι) (ω : α) => f n ω + g n ω) l fun (x : α) => 0

    f + g →_P 0 from each →_P 0. Proof: union bound, {|f+g|≥ε} ⊆ {|f|≥ε/2} ∪ {|g|≥ε/2} via triangle ineq, then measure_union_le + Tendsto.add on the ε/2-events.

    theorem MeasureTheory.TendstoInMeasure.sub_zero {α : Type u_1} {ι : Type u_2} {m : MeasurableSpace α} {μ : Measure α} {l : Filter ι} {f g : ι → α → ℝ} (hf : TendstoInMeasure μ f l fun (x : α) => 0) (hg : TendstoInMeasure μ g l fun (x : α) => 0) :
    TendstoInMeasure μ (fun (n : ι) (ω : α) => f n ω - g n ω) l fun (x : α) => 0

    f - g →_P 0 from each →_P 0. Composed from add_zero + neg_zero.
