    source
    theorem AsymptoticStatistics.L2Utils.sq_add_le_two_mul_sq (a b : ℝ) :
    (a + b) ^ 2 ≤ 2 * a ^ 2 + 2 * b ^ 2

    Pointwise inequality: (a + b)² ≤ 2 a² + 2 b². Follows from (a − b)² ≥ 0 ⇒ a² + b² ≥ 2ab ⇒ (a+b)² = a² + 2ab + b² ≤ 2(a² + b²).

    source
    theorem AsymptoticStatistics.L2Utils.sq_sub_le_two_mul_sq (a b : ℝ) :
    (a - b) ^ 2 ≤ 2 * a ^ 2 + 2 * b ^ 2

    Pointwise inequality: (a - b)² ≤ 2 a² + 2 b². Symmetric.

    Cauchy–Schwarz and Hölder specialisations #

    source
    theorem AsymptoticStatistics.L2Utils.abs_integral_mul_le_sqrt_integral_sq {𝓧 : Type u_1} [MeasurableSpace 𝓧] (μ : MeasureTheory.Measure 𝓧) {f g : 𝓧 → ℝ} (hf : MeasureTheory.MemLp f 2 μ) (hg : MeasureTheory.MemLp g 2 μ) :
    |∫ (x : 𝓧), f x * g x ∂μ| ≤ √(∫ (x : 𝓧), f x ^ 2 ∂μ) * √(∫ (x : 𝓧), g x ^ 2 ∂μ)

    Cauchy–Schwarz for real-valued integrals: |∫ f·g dμ| ≤ √(∫ f² dμ) · √(∫ g² dμ) for f, g ∈ L²(μ).

    Proof: lift f, g to Lp ℝ 2 μ, apply the abstract Cauchy–Schwarz real_inner_mul_inner_self_le, and translate the inner products back to integrals via MeasureTheory.L2.inner_def.

    theorem AsymptoticStatistics.L2Utils.tendsto_integral_sq_of_tendsto_integral_diff_sq {𝓧 : Type u_1} [MeasurableSpace 𝓧] (μ : MeasureTheory.Measure 𝓧) {f : ℕ → 𝓧 → ℝ} {g : 𝓧 → ℝ} (hg_memLp : MeasureTheory.MemLp g 2 μ) (hf_diff_memLp : ∀ᶠ (n : ℕ) in Filter.atTop, MeasureTheory.MemLp (fun (x : 𝓧) => f n x - g x) 2 μ) (h_diff_tendsto : Filter.Tendsto (fun (n : ℕ) => ∫ (x : 𝓧), (f n x - g x) ^ 2 ∂μ) Filter.atTop (nhds 0)) :
    Filter.Tendsto (fun (n : ℕ) => ∫ (x : 𝓧), f n x ^ 2 ∂μ) Filter.atTop (nhds (∫ (x : 𝓧), g x ^ 2 ∂μ))

    L² norm-square convergence from L²-difference convergence.

    If g ∈ L²(μ) and ∫(f_n − g)² dμ → 0, then ∫f_n² dμ → ∫g² dμ.

    Proof. f_n² = (f_n − g)² + 2(f_n − g)·g + g² pointwise. Integrate: ∫f_n² = ∫(f_n − g)² + 2∫(f_n − g)·g + ∫g². The first → 0 by hypothesis; the second → 0 by Cauchy–Schwarz |∫(f_n − g)·g| ≤ √(∫(f_n − g)²)·√(∫g²) → 0; the third is constant.

    theorem AsymptoticStatistics.L2Utils.tendsto_eLpNorm_div_ofReal_of_toReal_sq {𝓧 : Type u_1} [MeasurableSpace 𝓧] {μ : MeasureTheory.Measure 𝓧} {F : ℝ → 𝓧 → ℝ} (h_mem : ∀ᶠ (t : ℝ) in nhdsWithin 0 {0}ᶜ, MeasureTheory.MemLp (F t) 2 μ) (h_sq : Filter.Tendsto (fun (t : ℝ) => (MeasureTheory.eLpNorm (F t) 2 μ).toReal ^ 2 / t ^ 2) (nhdsWithin 0 {0}ᶜ) (nhds 0)) :
    Filter.Tendsto (fun (t : ℝ) => MeasureTheory.eLpNorm (F t) 2 μ / ENNReal.ofReal |t|) (nhdsWithin 0 {0}ᶜ) (nhds 0)

    Converse of .toReal²/t² → 0 ⇒ ℝ≥0∞-quotient → 0. If each F t is eventually in L²(μ) near 0 and (eLpNorm (F t) 2 μ).toReal² / t² → 0, then the ℝ≥0∞-quotient eLpNorm (F t) 2 μ / ENNReal.ofReal |t| → 0. This is the converse direction of Core/QMDPath.QMDPath.qmd_limit_toReal_sq, used to repackage the coarsened QMD residual bound into the ℝ≥0∞-form qmd_limit field.
