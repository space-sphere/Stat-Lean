    Pi-product of standard 1D Gaussians #

    Two basic facts about Measure.pi (fun _ => gaussianReal 0 1) on ι → ℝ:

    • pi_gaussianReal_eq_withDensity — the Pi-product Gaussian equals the Lebesgue measure on ι → ℝ tilted by the product density ∏ i, gaussianPDF 0 1 (x i).
    • pi_gaussianReal_neg_invariant — Pi-product Gaussian is preserved by x ↦ -x.

    Used by Anderson.lean (PL application + symmetry) and MultivariateGaussianWeakLimit.lean (AC chain for multivariateGaussian 0 S when S.PosDef).

    theorem AsymptoticStatistics.pi_gaussianReal_eq_withDensity {ι : Type u_1} [Fintype ι] :
    (MeasureTheory.Measure.pi fun (x : ι) => ProbabilityTheory.gaussianReal 0 1) = MeasureTheory.volume.withDensity fun (x : ι → ℝ) => ∏ i : ι, ProbabilityTheory.gaussianPDF 0 1 (x i)

    Measure.pi (gaussianReal 0 1) = volume.withDensity ρ where ρ x = ∏ i, gaussianPDF 0 1 (x i) is the standard Pi Gaussian density on ι → ℝ.

    Bridges Pi standard Gaussian to a Lebesgue density form. Closed via pi_withDensity_prod.

    theorem AsymptoticStatistics.pi_gaussianReal_neg_invariant {ι : Type u_1} [Fintype ι] :
    MeasureTheory.Measure.map (fun (x : ι → ℝ) => -x) (MeasureTheory.Measure.pi fun (x : ι) => ProbabilityTheory.gaussianReal 0 1) = MeasureTheory.Measure.pi fun (x : ι) => ProbabilityTheory.gaussianReal 0 1

    Pi standard Gaussian is invariant under negation x ↦ -x.

    Each component gaussianReal 0 1 is symmetric (gaussianReal_map_neg with mean 0); the Pi product preserves this via MeasureTheory.measurePreserving_pi.
