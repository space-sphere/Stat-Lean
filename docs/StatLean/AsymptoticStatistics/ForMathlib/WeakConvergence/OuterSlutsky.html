    Slutsky perturbation for weak convergence in outer expectation #

    This file proves the shared-base outer analogue of Slutsky's theorem. Neither map is assumed measurable: closeness is expressed by the outer value μ.real {ω | δ ≤ dist (X ω) (Y ω)}.
