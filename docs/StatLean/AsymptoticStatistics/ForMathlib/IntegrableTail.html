    L¹ tail integrals vanish along a diverging threshold.

    If h : α → ℝ is integrable, f : α → ℝ is measurable, and t : ℕ → ℝ satisfies t n → ∞, then ∫_{y : f y > t n} h(x) dμ → 0 as n → ∞.

    Proof. DCT on F n x := {y | t n < f y}.indicator h x:

    • Dominator: |h|, integrable by Integrable.abs.
    • Pointwise: for each x, f x is a finite real, so t n > f x eventually, which forces x ∉ {y | t n < f y} and hence the indicator vanishes eventually.
