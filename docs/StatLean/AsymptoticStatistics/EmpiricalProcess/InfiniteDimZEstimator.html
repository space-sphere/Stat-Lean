    Infinite-dimensional Z-estimator (vdV Theorem 19.26) #

    This is the ℓ∞(H)-indexed generalization of the scalar goodness-of-fit Theorem 19.23 (empiricalProcess_param_estimation). For a class 𝓕 = {ψ_{θ,h} : ‖θ − θ₀‖ < δcls, h ∈ H} that is P-Donsker with finite envelope, with θ ↦ Pψ_θ Fréchet-differentiable at a zero θ₀ with a bounded-below derivative V, and with sup_h P(ψ_{θ,h} − ψ_{θ₀,h})² → 0 as θ → θ₀: if √n ℙₙψ_{θ̂_n} = o_P(1) in ℓ∞(H) and θ̂_n →ₚ θ₀, then

    √n V(θ̂_n − θ₀) = −𝔾ₙψ_{θ₀} + o_P(1)   (in ℓ∞(H)).

    The parameter θ lies in a general normed space B; ℓ∞(H) is represented by plain functions H → ℝ; and the conclusion uses outer probability over the supremum across H (TendstoZeroInOuterProbSup). The √n ℙₙψ_{θ̂_n} rate is little-o_P, as in Theorem 5.21.

    Proof route: 5.21-style master identity + uniform Lemma 19.24 (uniform_donsker_random_function_consistency) + Fréchet remainder bound (frechet_remainder_sup_bound) + rate bootstrap (rate_bootstrap_oP).

    Headline declaration: infinite_dim_z_estimator.

    Bundled hypotheses for Theorem 19.26 (infinite-dimensional Z-estimator).

    Here B is a general normed space, H is arbitrary, and ℓ∞(H) is represented by H → ℝ. The Fréchet derivative V : B →ₗ[ℝ] (H → ℝ) is paired with the explicit bounded-below field bddbelow_V, encoding continuity of the inverse on its range.

    Only the sample-agnostic part of the book hypotheses lives here; the sample-specific tightness half of the Donsker hypothesis (h_tight) is a binder of the headline infinite_dim_z_estimator, since it references the iid sample μ, X.

    • hδcls : 0 < δcls

      Constitutive (vdV §19.4 p.281): the Donsker class radius δ is positive (𝓕 = {ψ_{θ,h} : ‖θ − θ₀‖ < δ} for some δ > 0).

    • hclass_mem (θ : B) : ‖θ - θ₀‖ < δcls → ∀ (h : H), ψ θ h ∈ 𝓕

      Constitutive (vdV §19.4 p.281): the class 𝓕 contains every ψ_{θ,h} with ‖θ − θ₀‖ < δcls (definition of the Donsker class).

    • hθ₀_mem (h : H) : ψ θ₀ h ∈ 𝓕

      Constitutive (vdV §19.4 p.281): the reference functions ψ_{θ₀,h} lie in 𝓕 (the class ball is centred at θ₀).

    • hψ_meas (θ : B) (h : H) : Measurable (ψ θ h)

      Constitutive (vdV §19.4 p.281): each x ↦ ψ_{θ,h}(x) is measurable ("let x ↦ ψ_{θ,h}(x) be a measurable function").

    • henv : ∃ (G : Ω → ℝ), IsEnvelope 𝓕 G ∧ MeasureTheory.Integrable G P

      Constitutive (vdV §19.4 p.281): 𝓕 has a finite (integrable) envelope function ("with finite envelope function").

    • h_equicont : IsAsymptoticallyEquicontinuous 𝓕 P

      Constitutive (vdV §19.4 p.281): 𝓕 is P-Donsker — this field records equicontinuity, while h_tight records the sample-specific tightness half.

    • hPθ₀_zero (h : H) : ∫ (x : Ω), ψ θ₀ h x ∂P = 0

      Constitutive (vdV §19.4 p.281): θ₀ is a zero of θ ↦ Pψ_θ, i.e. Pψ_{θ₀,h} = 0 for all h ("Fréchet-differentiable at a zero θ₀").

    • bddbelow_V : ∃ (c : ℝ), 0 < c ∧ ∀ (b : B), ENNReal.ofReal (c * ‖b‖) ≤ ⨆ (h : H), ENNReal.ofReal |V b h|

      Constitutive (vdV §19.4 p.281): V has a continuous inverse on its range, encoded as bounded-below in the ℓ∞(H) sup: ∃ c > 0, c‖b‖ ≤ ‖V b‖_H, in ENNReal-⨆ form.

    • frechet (ε : ℝ) : ε > 0 → ∃ δ > 0, ∀ (θ : B), 0 < ‖θ - θ₀‖ → ‖θ - θ₀‖ < δ → ⨆ (h : H), ENNReal.ofReal |∫ (x : Ω), ψ θ h x ∂P - ∫ (x : Ω), ψ θ₀ h x ∂P - V (θ - θ₀) h| ≤ ENNReal.ofReal (ε * ‖θ - θ₀‖)

      Constitutive (vdV §19.4 p.281): θ ↦ Pψ_θ is Fréchet-differentiable at θ₀ with derivative V. ε-δ sup-over-H form (mirrors Theorem19_23Hyp.frechet): sup_h |Pψ_{θ,h} − Pψ_{θ₀,h} − V(θ−θ₀)_h| ≤ ε‖θ − θ₀‖.

    • unif_L2_cont (ε : ℝ) : ε > 0 → ∃ δ > 0, ∀ (θ : B), ‖θ - θ₀‖ < δ → ⨆ (h : H), ENNReal.ofReal (distL2 P (ψ θ h) (ψ θ₀ h)) ≤ ENNReal.ofReal ε

      Constitutive (vdV §19.4 p.281): uniform L²-continuity of the family at θ₀, ‖P(ψ_{θ,h} − ψ_{θ₀,h})²‖_H → 0 as θ → θ₀. ε-δ sup-over-H form on distL2 (distL2² = P(ψ_θ − ψ_{θ₀})²).

      Theorem 19.26 (infinite-dimensional Z-estimator).

      Under Theorem19_26Hyp, an iid sample, the tightness half of the Donsker hypothesis (h_tight), consistency θ̂_n →ₚ θ₀ (h_consist), and the o_P(n^{-1/2}) estimating equation √n ℙₙψ_{θ̂_n} →ₚ 0 in ℓ∞(H) (h_est_eq), the centred estimator satisfies

      √n V(θ̂_n − θ₀) + 𝔾ₙψ_{θ₀} = o_P(1)   (in ℓ∞(H), outer probability),

      i.e. √n V(θ̂_n − θ₀) = −𝔾ₙψ_{θ₀} + o_P(1).

      Assembly: master_identity rearranges the target into √n ℙₙψ_{θ̂_n} (the o_P estimating equation h_est_eq) minus the uniform-19.24 remainder 𝔾ₙψ_{θ̂_n} − 𝔾ₙψ_{θ₀} (o_P via uniform_donsker_random_function_consistency fed by modifiedRandomFunction) minus S_n (o_P via frechet_remainder_sup_bound + rate_bootstrap_oP, using bddbelow_V and h_tight); oP_sup_add combines the three o_P pieces.
