    Hilbert geometry wrappers #

    This file packages the vdV §25.2 Hilbert-space background (orthogonal projection, Riesz representation, orthogonal decomposition) under the names the rest of the library uses, and introduces the central object L2ZeroMean P: the closed submodule of mean-zero functions in Lp ℝ 2 P.

    Headline declarations: L2ZeroMean, orthogonal_decomp, mem_of_orthogonal_complement_zero, riesz_repr_exists_unique.

          theorem AsymptoticStatistics.Core.Hilbert.mem_of_orthogonal_complement_zero {𝕜 : Type u_2} [RCLike 𝕜] {E : Type u_3} [NormedAddCommGroup E] [InnerProductSpace 𝕜 E] [CompleteSpace E] (K : Submodule 𝕜 E) (hK : IsClosed ↑K) (x : E) :
          x ∈ K ↔ ∀ y ∈ Kᗮ, inner 𝕜 y x = 0

          Membership in a closed submodule via orthogonality to the orthogonal complement.

          For a closed submodule K in a complete inner product space, Kᗮᗮ = K, so x ∈ K iff x is orthogonal to every element of Kᗮ.
