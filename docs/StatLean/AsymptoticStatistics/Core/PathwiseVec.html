    Vector-valued pathwise differentiability #

    This file defines pathwise differentiability for vector-valued statistical functionals ψ : Measure Ω → EuclideanSpace ℝ (Fin k), following van der Vaart, Asymptotic Statistics, §25.3.

    The headline declaration is PathwiseDifferentiableAt_vec.

    source
    structure AsymptoticStatistics.Core.PathwiseVec.PathwiseDifferentiableAt_vec {Ω : Type u_1} [MeasurableSpace Ω] (P : MeasureTheory.Measure Ω) [MeasureTheory.IsProbabilityMeasure P] (T : Submodule ℝ ↥(Hilbert.L2ZeroMean P)) {k : ℕ} (ψ : MeasureTheory.Measure Ω → EuclideanSpace ℝ (Fin k)) :
    Type u_1

    A vector-valued statistical functional ψ : Measure Ω → EuclideanSpace ℝ (Fin k) is pathwise differentiable at P relative to the tangent space T iff there exists a continuous-linear derivative dψ : T →L[ℝ] EuclideanSpace ℝ (Fin k) such that for every QMDPath at P whose score lies in T, the difference quotient (ψ(γ.curve t) - ψ P) / t converges to dψ ⟨γ.score, _⟩ as t → 0.

    vdV §25.3: the derivative is a continuous linear map from the tangent space directly into the vector codomain.

    • derivative : ↥T →L[ℝ] EuclideanSpace ℝ (Fin k)
