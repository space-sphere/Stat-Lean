    Benjamini–Hochberg FDR control under independence #

    The Benjamini–Hochberg procedure at level $\alpha$ tests $N$ null hypotheses from p-values $p_1,\dots,p_N$. In its classical form it orders the p-values $p_{(1)} \le \cdots \le p_{(N)}$, finds the largest index $i_{\max} = \max\{\, i : p_{(i)} \le i\alpha/N \,\}$, and rejects the $i_{\max}$ smallest p-values. Equivalently (the sort-free form used here) it rejects the set $\{\, j : p_j \le \hat{k}\,\alpha/N \,\}$, where $$\hat{k} = \max\bigl\{\, k \le N : \#\{\, j : p_j \le k\alpha/N \,\} \ge k \,\bigr\},$$ with $\hat{k}=0$ (no rejections) when no $k \ge 1$ satisfies the count condition.

    Main result (benjamini_hochberg_fdr_le). Suppose the p-values $p_1,\dots,p_N$ are jointly independent and every null p-value is super-uniform (i.e. $\Pr(p_j \le t) \le t$ for all $t \ge 0$ and $j$ in the null set $H_0$). Then the Benjamini–Hochberg procedure at level $\alpha$ controls the false discovery rate: $$\mathrm{FDR} \;\le\; \frac{N_0}{N}\,\alpha \;\le\; \alpha,$$ where $N_0 = |H_0|$ is the number of true nulls and the false discovery rate is the expected proportion of false rejections among all rejections, $\mathrm{FDR} = E[V/(R \vee 1)]$.

    Reference. Junwei Lu, Big Data Analysis, Springer Nature Switzerland, 2025 (ISBN 978-3-032-03160-0), Chapter 20 (False Discovery Rate), §20.2 (False Discovery Rate: Independent P-Values), Theorem 20.1. The same result appears as E. J. Candès, STAT 300C: Theory of Statistics, Lecture Notes, Stanford University, 2023, Lecture 7 (False Discovery Rate), §7.2 (Martingale Theory and FDR Control), Theorem 2, which states $E[\mathrm{FDP}(\tau_{BH})] = q\,n_0/n$ at level $q = \alpha$.

    Proof formalization notes. Book vs Lean. Lu-BDA Ch20 §20.2 (and Candès Lecture 7 §7.2, Theorem 2) states the equality $\mathrm{FDR} = (N_0/N)\,\alpha$ for exactly-uniform null p-values; we prove the honest inequality $\le$, which holds under the weaker super-uniform hypothesis and specializes to the book's equality when the nulls are exactly uniform.

    Proof outline (Lu-BDA §20.2): for each null index $i \in H_0$ the per-null contribution satisfies $E[\psi_i/(R \vee 1)] \le \alpha/N$ (bh_claim), where $\psi_i$ is the indicator that $i$ is rejected and $R$ is the total number of rejections. This uses the deterministic leave-one-out invariance bh_count_eq_leaveOneOut (replacing $p_i$ by the constant $0$ leaves the rejection count unchanged when $i$ is rejected) together with the tower property over the σ-algebra generated by the other p-values $\{p_j : j \ne i\}$, which is independent of $p_i$. Summing the per-null bound over $i \in H_0$ gives $\mathrm{FDR} \le (N_0/N)\,\alpha$.

    Bibliographic comments. The procedure and the FDR-control guarantee originate with Y. Benjamini and Y. Hochberg, "Controlling the false discovery rate: a practical and powerful approach to multiple testing", Journal of the Royal Statistical Society, Series B 57(1) (1995), 289–300. That paper introduces the false discovery rate as an error criterion and proves (its Theorem 1) that for independent test statistics the procedure controls the FDR at level $(m_0/m)\,q \le q$, where $m_0$ is the number of true null hypotheses among $m$ tests and $q$ is the chosen level — exactly the bound formalized here (with $m = N$, $m_0 = N_0$, $q = \alpha$).

    Benjamini–Hochberg rejection set at level α (Lu-BDA §20.2): reject { j : pⱼ ≤ k̂·α/N }, where k̂ = max{ k ≤ N : #{ j : pⱼ ≤ kα/N } ≥ k } (the sort-free form of iₘₐₓ). With no k ≥ 1 satisfying the count condition, k̂ = 0 and nothing is rejected.
