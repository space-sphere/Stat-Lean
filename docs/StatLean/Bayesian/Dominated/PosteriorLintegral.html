    Posterior expectation formula (dominated form) #

    The posterior expectation of a nonnegative functional, in dominated form: for predictive-a.e. x, $$\int_\Theta g(\theta)\,\pi(d\theta \mid x) = \frac{\int_\Theta g(\theta)\,p(\theta, x)\,\pi(d\theta)}{\int_\Theta p(\theta', x)\,\pi(d\theta')},$$ and its set-indicator special case π(s | x) = ∫_s p(·,x) dπ / ∫ p(·,x) dπ.

    Reference. C. P. Robert, The Bayesian Choice: From Decision-Theoretic Foundations to Computational Implementation, 2nd ed., Springer Texts in Statistics, Springer, 2007 (ISBN 978-0-387-71598-8). §1.4, p. 22 (the posterior and expectations under it); the formula is eq. (1.2.3) integrated against g.

    Proof formalization notes. Follows from posterior_eq_withDensity_likelihood_div_predictive by lintegral_withDensity_eq_lintegral_mul and pulling the constant (m x)⁻¹ out of the lintegral with lintegral_mul_const'' (unconditional in ℝ≥0∞, so no positivity hypotheses needed). Stated for ℝ≥0∞-valued g; a real-integrable version can follow later. Watch CLAUDE.md gotcha 12 (simp_rw after the withDensity rewrite).

    Bibliographic comments. Ratios of the form ∫ g·p dπ / ∫ p dπ are the computational core of Bayesian inference — already Laplace's 1774 memoir evaluates posterior expectations of exactly this shape, and their numerical approximation motivates the Monte Carlo and Laplace-approximation methods.

    theorem StatLean.Bayesian.posterior_lintegral_eq_div {Θ : Type u_1} {𝓧 : Type u_2} [mΘ : MeasurableSpace Θ] [m𝓧 : MeasurableSpace 𝓧] {κ : ProbabilityTheory.Kernel Θ 𝓧} {π : MeasureTheory.Measure Θ} {ν : MeasureTheory.Measure 𝓧} {p : Θ → 𝓧 → ENNReal} [StandardBorelSpace Θ] [Nonempty Θ] [MeasureTheory.IsFiniteMeasure π] [ProbabilityTheory.IsFiniteKernel κ] [MeasureTheory.SFinite ν] (hp : Measurable (Function.uncurry p)) (hκ : ∀ (θ : Θ), κ θ = ν.withDensity (p θ)) {g : Θ → ENNReal} (hg : Measurable g) :
    ∀ᵐ (x : 𝓧) ∂π.bind ⇑κ, ∫⁻ (θ : Θ), g θ ∂(ProbabilityTheory.posterior κ π) x = (∫⁻ (θ : Θ), g θ * p θ x ∂π) / ∫⁻ (θ' : Θ), p θ' x ∂π

    Posterior expectation formula (Robert §1.4): for predictive-a.e. x and measurable g ≥ 0, ∫ g dπ(·|x) = (∫ g·p(·,x) dπ) / (∫ p(·,x) dπ).

    theorem StatLean.Bayesian.posterior_apply_eq_div {Θ : Type u_1} {𝓧 : Type u_2} [mΘ : MeasurableSpace Θ] [m𝓧 : MeasurableSpace 𝓧] {κ : ProbabilityTheory.Kernel Θ 𝓧} {π : MeasureTheory.Measure Θ} {ν : MeasureTheory.Measure 𝓧} {p : Θ → 𝓧 → ENNReal} [StandardBorelSpace Θ] [Nonempty Θ] [MeasureTheory.IsFiniteMeasure π] [ProbabilityTheory.IsFiniteKernel κ] [MeasureTheory.SFinite ν] (hp : Measurable (Function.uncurry p)) (hκ : ∀ (θ : Θ), κ θ = ν.withDensity (p θ)) {s : Set Θ} (hs : MeasurableSet s) :
    ∀ᵐ (x : 𝓧) ∂π.bind ⇑κ, ((ProbabilityTheory.posterior κ π) x) s = (∫⁻ (θ : Θ) in s, p θ x ∂π) / ∫⁻ (θ' : Θ), p θ' x ∂π

    Set form of Robert eq. (1.2.3): π(s | x) = ∫_s p(·,x) dπ / ∫ p(·,x) dπ for predictive-a.e. x.
