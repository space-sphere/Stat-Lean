    Gradient at an extremum #

    Theorem-agnostic brick (ForMathlib layer): at an interior local (hence at a global) minimizer of a differentiable function, the gradient vanishes.

    This bridges Mathlib's Fermat-type IsLocalMin.fderiv_eq_zero to the Riesz-representation gradient, giving the ∇f(x*) = 0 fact used in the unconstrained gradient-descent analysis (Junwei Lu, Big Data Analysis, Springer Nature Switzerland, 2025 (ISBN 978-3-032-03160-0), Ch. 13 (Gradient Descent), §13.1; the gradient-vanishing brick behind Theorem 13.1 (Convergence of Gradient Descent)).

    source
    theorem StatLean.Optimization.gradient_eq_zero_of_forall_le {E : Type u_1} [NormedAddCommGroup E] [InnerProductSpace ℝ E] [CompleteSpace E] {f : E → ℝ} (hdiff : Differentiable ℝ f) {x : E} (hmin : ∀ (y : E), f x ≤ f y) :
    gradient f x = 0

    At a global minimizer of a differentiable function, the gradient is zero.
